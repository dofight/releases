# Dofight

L'assistant de combat pour Dofus : un overlay qui affiche, pour les monstres du combat, ce qui peut te faire perdre
(one-shots, invulnérabilités, mécaniques), leurs résistances et leurs sorts.

## Installer

1. Ouvre la dernière version : [Releases](https://github.com/dofight/releases/releases/latest).
2. Télécharge `Dofight_..._x64-setup.exe` et lance-le.
3. Dans Dofus, coche **« Afficher les coordonnées de la carte »** dans les options.

Dofight se met ensuite à jour tout seul à chaque lancement.

Dofight ne fait que regarder l'écran : il n'envoie rien au jeu, ne lit ni sa mémoire ni son trafic réseau.
Données : [Dofensive](https://dofensive.com). Guides : [Dofus pour les Noobs](https://www.dofuspourlesnoobs.com).
